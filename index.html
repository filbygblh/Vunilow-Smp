Join

Two editions, two addresses

Pick the one you play on. The version updates itself, so you always know what the server is running.

Java Edition

PC / Mac
  1. Open Minecraft Java, version 26.2 or below.
  2. Go to Multiplayer then Add Server.
  3. Enter Vunilowsmp.net as the address and join.

Bedrock Edition

Console / Mobile
  1. Open Minecraft Bedrock and go to Play then Servers.
  2. Choose Add Server.
  3. Address VunilowSmp.net, port 25565, then join.
FAQ

Before you jump in

The questions that come up most often on the server.

What version do I need?

Java players can join on any version up to the one shown in the server panel at the top of this page. Bedrock players connect through the same address on port 25565.

Can I play from Bedrock?

Yes. Add a server in Minecraft Bedrock with the address Vunilowsmp.net and port 25565, then join. Console players may need to allow external servers in their console's network settings.

Do I need mods?

No — vanilla clients can join. If you want proximity voice chat, install the Simple Voice Chat mod for your Minecraft version.

How do I report a cheater or a bug?

Run /discord in-game to get the Discord invite, then report it to staff with as much detail as you can.

Can I bring friends?

Yes. Send them the address, or use the copy button in the server panel at the top of the page. New players should read the rules first.
