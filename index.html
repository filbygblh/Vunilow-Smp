About

Built around the shop

Vunilow Smp is a Donut SMP style survival server. Earn money, trade with players, and build your way up in a world that isn't going anywhere.

Shop survival

Voice chat

Join

Two editions, two addresses

Pick the one you play on. The version updates itself, so you always know what the server is running.

Java Edition

PC / Mac
  1. Open Minecraft Java, version 26.2 or below.
  2. Go to Multiplayer then Add Server.
  3. Enter Vunilowsmp.net as the address and join.

Bedrock Edition

Console / Mobile
  1. Open Minecraft Bedrock and go to Play then Servers.
  2. Choose Add Server.
  3. Address VunilowSmp.net, port 25565, then join.
