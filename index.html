About the server

VunilowSmp is a Donut SMP style survival server. Play on Minecraft 26.2 or any earlier version.

Shop survival

Earn money, buy and sell in the shop, and build your way up in a survival world.

Java + Bedrock

Play on either edition. Friends can join together, whatever they play on.

Voice chat

Simple Voice Chat is supported, so you can talk to players close to you in the world.

Version 26.2 and below

Use 26.2 or any older version. No need to update to join.

How to join

Java Edition

  1. Open Minecraft Java, version 26.2 or below.
  2. Go to Multiplayer, then Add Server.
  3. Enter Vunilowsmp.net as the address and join.

Bedrock Edition

  1. Open Minecraft Bedrock and go to Play, then Servers.
  2. Choose Add Server.
  3. Enter Vunilowsmp.net as the address and 25565 as the port, then join.
